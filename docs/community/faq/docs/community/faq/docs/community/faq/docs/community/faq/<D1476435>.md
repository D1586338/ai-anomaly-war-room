title: 什麼是告警自動降級？
author: war-room-maintainer
created: 2026-11-25
說明
當系統偵測到異常指標已逐漸回穩，或持續時間未達高嚴重度升級條件時，會自動將原本的緊急告警調整為較低等級（例如從 P1 降為 P2 或 P3）。這用來協助值班人員優先處理仍在惡化的核心事件，避免過度分配應變資源。

使用者下一步
確認指標趨勢是否持續收斂；若後續數值再次突破門檻，系統將重新升級告警，或可由人員視現場狀況手動調整等級。
